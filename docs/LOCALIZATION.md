# 界面本地化

设置 → 语言 / Language 提供“跟随 Dalamud / Auto”、English、简体中文。
旧配置默认跟随 Dalamud：中文使用简体中文，其他语言使用英文。
选择会保存；界面在下一帧更新，不改变导出格式或进程文化。

首版覆盖角色、动画、区域、布局、设置、关于页面的常用操作、导出提示和更新窗口控件。
技术检查面板、底层日志、异常详情、历史更新正文和第三方文件选择器自带控件保持原文。
模型、骨骼、文件路径和技术枚举标识不翻译。

## 添加或修改翻译

资源在 `Meddle/Meddle.Plugin/Localization/en.json` 和 `zh-CN.json`，嵌入插件 DLL。
为每条文字使用稳定语义键，两份资源同时更新。句子保持完整，动态值使用 `{0}` 等占位符。
`Loc.Text` 用于普通文字，`Loc.Format` 用于参数文本；交互控件使用 `Loc.Label` 或 `Loc.LabelFormat`，
它们通过 `###` 保持与译文无关的 ImGui ID。不要将这些带 ID 的标签用于文件名、日志或导出元数据。
译文缺失时回退英文。资源键也不存在时显示键名，便于定位遗漏。

插件通过 Dalamud 托管字体图集，在默认字体上合并 Windows 微软雅黑中译文所需字符；
仅在插件窗口绘制期间压入字体，图标继续使用图标字体。字体句柄随插件卸载释放。
未安装微软雅黑时使用 Dalamud 默认字体，中文显示取决于其字符覆盖。

## 验证

`dotnet test Meddle/Meddle.Utils.Tests/Meddle.Utils.Tests.csproj --filter FullyQualifiedName~LocalizationTests`
检查语言映射、资源键、占位符、控件 ID、字符范围，以及全局文化不被修改。

游戏内还需检查：

- Dalamud 为英文时手动选择中文，设置项和中文语言名称无方框。
- 更改 Dalamud 语言，自动模式跟随；手动模式不受影响。
- 切换语言后标签页、展开项、输入内容保留；重启后保存的语言不变。
- 角色、动画、布局、区域导出可启动、取消；导出路径和技术标识不随语言变化。
- 常用窗口在不同 UI 缩放下无明显截断，更新窗口和图标显示正常。

自动检查和编译不代替以上游戏内验收。
